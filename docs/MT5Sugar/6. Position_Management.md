# MT5Sugar — Position Management (High-Level API)

> Close and modify positions in one line — full, partial, all, by symbol, SL/TP.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [`MT5Service.closeOrder` / `modifyOrder`](../MT5Service/4.%20Trading_Methods.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/08_sugar_positions.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Action |
|--------|---------|--------|
| **`closePosition(ticket)`** | `Promise<boolean>` | Close a position fully (deletes a pending). **Throws** on rejection. |
| **`closePositionPartial(ticket, volume)`** | `Promise<boolean>` | Close `volume` lots. **Throws** on rejection. |
| **`closeAllPositions()`** | `Promise<number>` | Close every position; returns how many. |
| **`closeAllBySymbol(symbol)`** | `Promise<number>` | Close all positions on one symbol; returns how many. |
| **`modifyPositionSL(ticket, sl)`** | `Promise<boolean>` | Set stop-loss (keeps TP). |
| **`modifyPositionTP(ticket, tp)`** | `Promise<boolean>` | Set take-profit (keeps SL). |
| **`modifyPositionSLTP(ticket, sl, tp)`** | `Promise<boolean>` | Set both SL and TP. |

> **Two result styles:** `closePosition` / `closePositionPartial` **throw** `MrpcError` on rejection (and return `true` on success); the `modify*` methods **return `false`** on a non-`10009` result instead of throwing. The `closeAll*` methods skip individual failures and return the count actually closed.

---

## 💡 Usage examples

### 1) Close one position

```ts
await sugar.closePosition(ticket); // throws if rejected
```

### 2) Partial close (half)

```ts
const p = await sugar.getPositionByTicket(ticket);
if (p) await sugar.closePositionPartial(ticket, p.volume / 2);
```

### 3) Flatten everything

```ts
const n = await sugar.closeAllPositions();
console.log(`closed ${n} positions`);
```

### 4) Close a basket by symbol

```ts
await sugar.closeAllBySymbol('EURUSD');
```

### 5) Move stop to break-even

```ts
const p = await sugar.getPositionByTicket(ticket);
if (p && p.type === 0 && p.priceCurrent > p.priceOpen) { // BUY in profit
  await sugar.modifyPositionSL(ticket, p.priceOpen);
}
```

### 6) Set both SL and TP

```ts
const ok = await sugar.modifyPositionSLTP(ticket, 1.0800, 1.0950);
console.log(ok ? 'updated' : 'rejected');
```

---

## 🔧 Notes

- **Mixed error styles** (above) — wrap `closePosition*` in `try/catch`; check the boolean for `modify*`.
- **`closeAll*` are resilient** — a single rejection doesn't abort the batch; the return value is the number closed.
- **Partial close** keeps the remainder open with the same ticket.

## 🎯 Summary

Position management sugar covers close (full / partial / all / by symbol) and modify (SL / TP / both). Closes throw on rejection; modifies return a boolean; the batch closers return a count and swallow individual failures.
