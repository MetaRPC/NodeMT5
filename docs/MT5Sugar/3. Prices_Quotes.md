# MT5Sugar — Prices & Quotes (High-Level API)

> Bid, ask, spread and a compact price snapshot — plus a price-watch helper.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [MT5Service](../MT5Service/MT5Service.Overview.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Value |
|--------|---------|-------|
| **`getBid(symbol)`** | `Promise<number>` | Current bid. |
| **`getAsk(symbol)`** | `Promise<number>` | Current ask. |
| **`getSpread(symbol)`** | `Promise<number>` | `ask − bid`, in price units. |
| **`getPriceInfo(symbol)`** | `Promise<PriceInfo>` | Bid / ask / spread-in-pips / time in one snapshot. |
| **`waitForPrice(symbol, targetBid, timeoutMs?)`** | `Promise<PriceInfo \| null>` | Poll until the bid reaches a target. |

---

## 📦 `PriceInfo` (DTO)

| Field | Type | Description |
| ----- | ---- | ----------- |
| `symbol` | `string` | Instrument. |
| `bid` / `ask` | `number` | Best prices. |
| `spreadPips` | `number` | Spread expressed in **pips** (pip = `point × 10` on 3/5-digit symbols). |
| `time` | `number` | Tick time — **milliseconds** since epoch. |

---

## 📖 Method details

### `getBid` / `getAsk` / `getSpread`

Single values pulled from the live tick. `getSpread` returns the raw price difference; for the pip-normalised spread use `getPriceInfo().spreadPips`.

### `getPriceInfo(symbol)`

One snapshot combining the tick and the symbol's pip size — `bid`, `ask`, `spreadPips`, `time`. Internally fetches the tick and the spec in parallel (`Promise.all`).

### `waitForPrice(symbol, targetBid, timeoutMs = 10000)`

Polls (~every 500 ms) until the **bid ≥ `targetBid`**, then returns the `PriceInfo` seen. Pass `targetBid = 0` to just wait for the next price. Returns `null` on timeout.

## 💡 Usage examples

### 1) Spread right now

```ts
const info = await sugar.getPriceInfo('EURUSD');
console.log(`${info.symbol}: ${info.bid}/${info.ask} · ${info.spreadPips.toFixed(1)} pips`);
```

### 2) BUY only on a tight spread

```ts
if ((await sugar.getPriceInfo('EURUSD')).spreadPips <= 1.5) {
  await sugar.buyMarket('EURUSD', 0.1);
}
```

### 3) Wait for a breakout level

```ts
const hit = await sugar.waitForPrice('EURUSD', 1.1000, 30000);
console.log(hit ? `reached ${hit.bid}` : 'timed out');
```

### 4) Raw bid/ask

```ts
const [bid, ask] = [await sugar.getBid('EURUSD'), await sugar.getAsk('EURUSD')];
console.log('mid:', ((bid + ask) / 2).toFixed(5));
```

### 5) Entry price for a calc

```ts
const ask = await sugar.getAsk('XAUUSD');
const { sl, tp } = await sugar.calculateSLTP('XAUUSD', 'BUY', ask, 100, 200);
```

---

## 🔧 Notes

- **Live source.** These read the current tick — reliable, unlike stale property prices.
- **Pips vs price units.** `getSpread` is in price units; `PriceInfo.spreadPips` is pip-normalised.
- **`waitForPrice` polls, not streams.** For a continuous feed use [`streamTicks`](../MT5Service/6.%20Streaming_Methods.md) / [`onTick`](./MT5Sugar.API_Overview.md).

## 🎯 Summary

Price sugar gives single values (`getBid` / `getAsk` / `getSpread`), a combined `PriceInfo` snapshot with pip-normalised spread, and `waitForPrice` to block until a level is reached. For continuous updates, drop to the tick stream.
