# MT5Sugar — Trading Helpers (High-Level API)

> Market orders with SL/TP given as **pip distances** from entry — the most convenient way to open a protected trade.

**🧩 API Layer:** **HIGH-LEVEL** — composed over [`calculateSLTP`](./10.%20Risk_Management.md) + [Trading with SL/TP](./5.%20Trading_SLTP.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Order |
|--------|---------|-------|
| **`buyMarketWithPips(symbol, volume, stopLossPips, takeProfitPips)`** | `Promise<number>` | Market BUY; SL/TP as pip distances. |
| **`sellMarketWithPips(symbol, volume, stopLossPips, takeProfitPips)`** | `Promise<number>` | Market SELL; SL/TP as pip distances. |

> These compute absolute levels from the **current price** via [`calculateSLTP`](./10.%20Risk_Management.md), then place the order through the SL/TP variants. They **return the ticket** and **throw `MrpcError`** on rejection, like the rest of the trading sugar.

> Looking for `calculateSLTP` itself? It lives in [Risk Management](./10.%20Risk_Management.md).

## 💡 Usage examples

### 1) BUY with 20/40 pips

```ts
const ticket = await sugar.buyMarketWithPips('EURUSD', 0.1, 20, 40); // 20-pip SL, 40-pip TP
```

### 2) SELL with symmetric stops

```ts
await sugar.sellMarketWithPips('EURUSD', 0.1, 30, 30);
```

### 3) Risk-sized, pip-defined entry

```ts
const lots = await sugar.calculatePositionSize('EURUSD', 1, 20); // 1% risk, 20-pip stop
const ticket = await sugar.buyMarketWithPips('EURUSD', lots, 20, 40);
```

### 4) Guarded entry

```ts
const { ok, reason } = await sugar.canOpenPosition('EURUSD', 0.1);
if (!ok) throw new Error(reason);
await sugar.buyMarketWithPips('EURUSD', 0.1, 25, 50);
```

### 5) Handle a closed market

```ts
try {
  await sugar.sellMarketWithPips('EURUSD', 0.1, 20, 40);
} catch (e) {
  if ((e as Error).message.includes('10018')) console.log('market closed');
  else throw e;
}
```

---

## 🔧 Notes

- **Pip = `point × 10`** on 3/5-digit symbols, else `point` — the same convention as [Risk Management](./10.%20Risk_Management.md).
- **Levels from the live quote.** Entry defaults to the current ask (BUY) / bid (SELL).
- **Mind the stop level.** SL/TP must clear [`getMinStopLevel`](./9.%20Symbol_Information.md) or expect retcode `10016`.
