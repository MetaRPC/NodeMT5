# MT5Sugar — Connection (High-Level API)

> One-liner connect and liveness checks — the fastest way onto the terminal.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners with smart defaults over [MT5Service](../MT5Service/MT5Service.Overview.md) / [MT5Account](../MT5Account/MT5Account.Master.Overview.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 🧱 Build the stack & reach the layers below

```ts
import { MT5Sugar } from '@metarpc/nodemt5';

// create() builds Service → Account underneath in one call
const sugar = MT5Sugar.create('mt5.mrpc.pro', 443);

await sugar.quickConnect(5057947437, 'password', 'MetaQuotes-Demo');
// … use it …
await sugar.service().disconnect(true);
```

* `MT5Sugar.create(host?, port?, apiKey?, id?)` → the whole stack (defaults `mt5.mrpc.pro:443`).
* `sugar.service()` → the `MT5Service` underneath · `sugar.account()` → the `MT5Account`.

---

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`quickConnect(login?, password?, server?)`** | `Promise<boolean>` | Connect; falls back to env vars. |
| **`isConnected()`** | `boolean` | `true` after a successful connect. |
| **`ping()`** | `Promise<boolean>` | Liveness probe — terminal connected & alive. |

---

## 📖 Method details

### `quickConnect(login?, password?, server?)`

Connects by login / password / server. **Any omitted argument falls back to an env var** — `MT5_LOGIN`, `MT5_PASSWORD`, `MT5_SERVER` — so you can keep credentials out of code. Throws `MrpcError` if none of the three is available.

```ts
// explicit
await sugar.quickConnect(5057947437, 'password', 'MetaQuotes-Demo');

// from env (MT5_LOGIN / MT5_PASSWORD / MT5_SERVER)
await sugar.quickConnect();
```

### `isConnected()`

Synchronous flag — no round-trip. `true` once `quickConnect` has succeeded.

### `ping()`

A lightweight health check against the terminal; returns `false` instead of throwing if the terminal is down — safe to call in a loop.

## 💡 Usage examples

### 1) Connect from environment

```ts
const sugar = MT5Sugar.create();
if (!(await sugar.quickConnect())) throw new Error('connect failed');
console.log('connected:', sugar.isConnected());
```

### 2) Reconnect guard before an action

```ts
if (!sugar.isConnected() || !(await sugar.ping())) {
  await sugar.quickConnect();
}
```

### 3) Liveness heartbeat

```ts
const timer = setInterval(async () => {
  console.log(new Date().toLocaleTimeString(), (await sugar.ping()) ? '🟢 alive' : '🔴 down');
}, 5000);
// later: clearInterval(timer);
```

### 4) Clean shutdown (frees the trial terminal)

```ts
try {
  // … work …
} finally {
  await sugar.service().disconnect(true); // true = delete the terminal, free the slot
}
```

---

## 🔧 Notes

- **Env fallback** makes `quickConnect()` with no args the norm in scripts — set `MT5_LOGIN` / `MT5_PASSWORD` / `MT5_SERVER`.
- **`ping()` never throws** — it's a boolean probe, unlike other calls which reject on error.
- **Free the terminal** with `disconnect(true)` at the end of a one-shot run (a trial allows one terminal per IP).

## 🎯 Summary

Connection sugar is three calls: `quickConnect` (explicit or from env), `isConnected` (sync flag) and `ping` (safe liveness probe). `create()` builds the whole stack; `service()` / `account()` drop you to the layers below.
