# MT5Sugar — Account Information (High-Level API)

> The full account snapshot, and a one-call win/loss summary of today.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [MT5Service](../MT5Service/1.%20Account_Methods.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js` · `09_sugar_history.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Value |
|--------|---------|-------|
| **`getAccountInfo()`** | `Promise<AccountInfo>` | Full account snapshot. |
| **`getDailyStats()`** | `Promise<DailyStats>` | Today's win/loss summary. |

> `AccountInfo` (`login`, `balance`, `equity`, `freeMargin`, `leverage`, `currency`, `tradeMode`, …) is documented in [MT5Service → Account Methods](../MT5Service/1.%20Account_Methods.md).

---

## 📦 `DailyStats` (DTO)

Computed from the **positions opened today** (net = `profit + swap + commission + fee`):

| Field | Type | Description |
| ----- | ---- | ----------- |
| `totalDeals` | `number` | Count of closed positions today. |
| `winningDeals` | `number` | Of those, net ≥ 0. |
| `losingDeals` | `number` | Of those, net < 0. |
| `winRate` | `number` | `winning / total`, percent. |
| `totalProfit` | `number` | Sum of net results. |
| `bestDeal` | `number` | Largest single net. |
| `worstDeal` | `number` | Smallest (most negative) net. |

## 💡 Usage examples

### 1) Account header

```ts
const a = await sugar.getAccountInfo();
console.log(`#${a.login} · ${a.balance} ${a.currency} · 1:${a.leverage} · ${a.tradeMode}`);
```

### 2) Today's scorecard

```ts
const s = await sugar.getDailyStats();
console.log(`${s.totalDeals} trades · win ${s.winRate.toFixed(0)}% · P&L ${s.totalProfit.toFixed(2)}`);
console.log(`best ${s.bestDeal.toFixed(2)} · worst ${s.worstDeal.toFixed(2)}`);
```

### 3) Demo vs real guard

```ts
if ((await sugar.getAccountInfo()).tradeMode === 'REAL') console.log('🚨 live account');
```

### 4) Stop trading after a daily loss limit

```ts
const s = await sugar.getDailyStats();
if (s.totalProfit <= -100) {
  console.log('daily loss limit hit — flattening');
  await sugar.closeAllPositions();
}
```

### 5) Win-rate gate

```ts
const s = await sugar.getDailyStats();
if (s.totalDeals >= 10 && s.winRate < 40) console.log('⚠️ win rate low today');
```

---

## 🔧 Notes

- **`getDailyStats` counts closed positions opened today** (local day) — `net` includes swap, commission and fee, not just `profit`.
- **For other windows** (week/month, custom range) use [History & Statistics](./8.%20History_Statistics.md).
- **For single figures** (balance, equity, free margin) use [Balance & Margin](./2.%20Balance_Margin.md).
