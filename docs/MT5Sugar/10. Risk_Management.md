# MT5Sugar — Risk Management (High-Level API)

> Size positions by risk, cap by free margin, pre-flight a trade, and compute SL/TP levels.

**🧩 API Layer:** **HIGH-LEVEL** — composed calculators over [MT5Service](../MT5Service/MT5Service.Overview.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/10_sugar_advanced.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

## 📋 Methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`calculatePositionSize(symbol, riskPercent, stopLossPips)`** | `Promise<number>` | Lots so a `stopLossPips` stop risks `riskPercent`% of balance. |
| **`getMaxLotSize(symbol)`** | `Promise<number>` | Largest lot 80% of free margin can open. |
| **`canOpenPosition(symbol, volume)`** | `Promise<{ ok: boolean; reason: string }>` | Pre-flight: availability, volume bounds, margin. |
| **`calculateRequiredMargin(symbol, volume)`** | `Promise<number>` | Margin for `volume` lots at the current ask. |
| **`calculateSLTP(symbol, direction, entryPrice, stopLossPips, takeProfitPips)`** | `Promise<{ sl: number; tp: number }>` | Absolute SL/TP from pip distances. |

---

## 📖 Method details

### `calculatePositionSize(symbol, riskPercent, stopLossPips)`

Returns a lot size such that hitting a `stopLossPips` stop loses about `riskPercent`% of the current **balance**. Uses the symbol's tick value / tick size and clamps to the symbol's min/max/step. Throws if `stopLossPips <= 0` or tick data is bad.

### `getMaxLotSize(symbol)`

Largest lot the current **free margin** can open, using only **80%** of it as a safety buffer. Falls back to `volumeMin` if margin-per-lot can't be computed.

### `canOpenPosition(symbol, volume)`

A single pre-flight check returning `{ ok, reason }`. Fails (`ok: false`, with a human `reason`) when the symbol is unavailable, the volume is below min / above max, or the required margin exceeds free margin.

### `calculateRequiredMargin(symbol, volume)`

Margin to open `volume` lots at the **current ask** (wraps `MT5Service.calculateMargin('BUY', …)`).

### `calculateSLTP(symbol, direction, entryPrice, stopLossPips, takeProfitPips)`

Absolute `sl` / `tp` prices from pip distances. `direction` is `'BUY'` or `'SELL'`; pass `entryPrice = 0` to use the live ask (BUY) / bid (SELL). Geometry: BUY → `sl` below, `tp` above; SELL → mirrored.

## 💡 Usage examples

### 1) Risk-based sizing

```ts
const lots = await sugar.calculatePositionSize('EURUSD', 1, 20); // risk 1% over a 20-pip stop
```

### 2) Cap by free margin

```ts
const max = await sugar.getMaxLotSize('EURUSD');
console.log('max lots:', max);
```

### 3) Pre-flight before sending

```ts
const { ok, reason } = await sugar.canOpenPosition('EURUSD', 0.5);
if (!ok) throw new Error(reason);
await sugar.buyMarket('EURUSD', 0.5);
```

### 4) Margin for a size

```ts
console.log('margin for 1 lot:', (await sugar.calculateRequiredMargin('EURUSD', 1)).toFixed(2));
```

### 5) SL/TP from pips at market

```ts
const { sl, tp } = await sugar.calculateSLTP('EURUSD', 'BUY', 0, 20, 40); // live ask, 20/40 pips
await sugar.buyMarketWithSLTP('EURUSD', 0.1, sl, tp);
```

### 6) Full risk-managed entry

```ts
const symbol = 'EURUSD';
const lots = await sugar.calculatePositionSize(symbol, 1, 20);
const { ok, reason } = await sugar.canOpenPosition(symbol, lots);
if (!ok) throw new Error(reason);
const { sl, tp } = await sugar.calculateSLTP(symbol, 'BUY', 0, 20, 40);
await sugar.buyMarketWithSLTP(symbol, lots, sl, tp);
```

## 🔧 Notes

- **Pips, not points.** Sizing/levels use pips (`point × 10` on 3/5-digit symbols) — consistent with the trading helpers.
- **`getMaxLotSize` keeps a 20% buffer** (uses 80% of free margin).
- **`calculatePositionSize` risks the balance**, clamped to the symbol's volume rules.
- **`calculateRequiredMargin` prices at the ask** (BUY side) — a good proxy for either direction.

## 🎯 Summary

Risk sugar turns account and symbol facts into decisions: size by risk (`calculatePositionSize`), cap by margin (`getMaxLotSize`), pre-flight (`canOpenPosition`), margin cost (`calculateRequiredMargin`) and SL/TP levels (`calculateSLTP`). Compose them for a fully risk-managed entry.
