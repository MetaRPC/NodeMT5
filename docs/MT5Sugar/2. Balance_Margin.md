# MT5Sugar — Balance & Margin (High-Level API)

> Single-number account reads — balance, equity, margin, free margin, level, floating profit.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [MT5Service](../MT5Service/MT5Service.Overview.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Value |
|--------|---------|-------|
| **`getBalance()`** | `Promise<number>` | Balance (excludes floating P/L). |
| **`getEquity()`** | `Promise<number>` | Equity (balance + floating P/L). |
| **`getMargin()`** | `Promise<number>` | Margin currently in use. |
| **`getFreeMargin()`** | `Promise<number>` | Free margin for new positions. |
| **`getMarginLevel()`** | `Promise<number>` | Margin level, % (0 when flat). |
| **`getProfit()`** | `Promise<number>` | Floating profit (`equity − balance`). |

> Each reads a field of the account snapshot ([`getAccountSummary`](../MT5Service/1.%20Account_Methods.md)). When you need **several** figures at once, read the snapshot directly — one round-trip instead of many.

---

## 💡 Usage examples

### 1) Quick balance line

```ts
console.log(`Balance ${await sugar.getBalance()} · Equity ${await sugar.getEquity()}`);
```

### 2) Margin-level health

```ts
const level = await sugar.getMarginLevel();
if (level > 0 && level < 100)      console.warn('⚠️ margin level critical');
else if (level > 0 && level < 200) console.warn('⚠️ low margin level');
```

### 3) Floating P&L watch

```ts
const timer = setInterval(async () => {
  console.log('floating:', (await sugar.getProfit()).toFixed(2));
}, 2000);
// later: clearInterval(timer);
```

### 4) Prefer one snapshot for several values

```ts
// ❌ three round-trips
const b = await sugar.getBalance(), e = await sugar.getEquity(), f = await sugar.getFreeMargin();

// ✅ one round-trip
const a = await sugar.service().getAccountSummary();
console.log(a.balance, a.equity, a.freeMargin);
```

### 5) Affordability gate

```ts
const free = await sugar.getFreeMargin();
if (free < 50) console.log('too little free margin to trade');
```

---

## 🔧 Notes

- **`getProfit()` is floating P&L**, computed as `equity − balance` — not realized profit (see [History & Statistics](./8.%20History_Statistics.md) for that).
- **`getMarginLevel()` is 0 when flat** (no open positions → no used margin).
- **Batching:** for 2+ values, call `sugar.service().getAccountSummary()` once rather than several getters.

## 🎯 Summary

Six one-liners return single account figures straight as numbers. They're convenient for a single value or a quick check; for a dashboard of several figures, read `getAccountSummary()` once.
