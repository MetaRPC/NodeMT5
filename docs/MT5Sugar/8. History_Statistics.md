# MT5Sugar — History & Statistics (High-Level API)

> Closed positions and realized profit over ready-made time windows — today, yesterday, this week/month, or custom.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [`MT5Service.getPositionsHistory`](../MT5Service/3.%20Position_Orders_Methods.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/09_sugar_history.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Window |
|--------|---------|--------|
| **`getDealsToday()`** | `Promise<HistoryPosition[]>` | Closed positions opened today. |
| **`getDealsYesterday()`** | `Promise<HistoryPosition[]>` | …opened yesterday. |
| **`getDealsThisWeek()`** | `Promise<HistoryPosition[]>` | …since Monday. |
| **`getDealsThisMonth()`** | `Promise<HistoryPosition[]>` | …since the 1st. |
| **`getDealsDateRange(from, to)`** | `Promise<HistoryPosition[]>` | …in a custom `Date` range. |
| **`getProfitToday()`** | `Promise<number>` | Net profit of today's closed positions. |
| **`getProfitThisWeek()`** | `Promise<number>` | …this week. |
| **`getProfitThisMonth()`** | `Promise<number>` | …this month. |

> Returns **`HistoryPosition`** rows (closed positions with `profit`, `swap`, `commission`, `fee`, `openTime`, `closeTime`, …) — documented in [MT5Service → Positions & Orders](../MT5Service/3.%20Position_Orders_Methods.md). The windows are built from **local** day/week/month boundaries (server day approximated by local day).

## 💡 Usage examples

### 1) Today's closed trades

```ts
const closed = await sugar.getDealsToday();
console.log(`${closed.length} closed today`);
```

### 2) Realized P&L this week

```ts
console.log('this week:', (await sugar.getProfitThisWeek()).toFixed(2));
```

### 3) Custom range

```ts
const from = new Date('2026-11-01');
const to = new Date();
const rows = await sugar.getDealsDateRange(from, to);
console.log('since Nov 1:', rows.length, 'positions');
```

### 4) Win rate this month

```ts
const rows = await sugar.getDealsThisMonth();
const wins = rows.filter((p) => p.profit >= 0).length;
console.log(`win rate: ${rows.length ? ((wins / rows.length) * 100).toFixed(0) : 0}%`);
```

### 5) Best / worst of the day

```ts
const rows = await sugar.getDealsToday();
if (rows.length) {
  console.log('best', Math.max(...rows.map((p) => p.profit)).toFixed(2));
  console.log('worst', Math.min(...rows.map((p) => p.profit)).toFixed(2));
}
```

### 6) Three windows side by side

```ts
const [d, w, m] = await Promise.all([sugar.getProfitToday(), sugar.getProfitThisWeek(), sugar.getProfitThisMonth()]);
console.log(`today ${d.toFixed(2)} · week ${w.toFixed(2)} · month ${m.toFixed(2)}`);
```

---

## 🔧 Notes

- **"Deals" = closed positions here.** These wrap `getPositionsHistory`, so each row is a closed position, not a raw deal — use [`MT5Service.getOrderHistory`](../MT5Service/3.%20Position_Orders_Methods.md) for raw deals.
- **Local boundaries.** Windows use the local clock; for exact server-day cutoffs, pass explicit `Date`s to `getDealsDateRange`.
- **`getProfit*` sums `profit`** of the window's positions.
