# MT5Sugar — Symbol Information (High-Level API)

> Quick symbol facts — full spec, name list, availability, stop level, digits.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [MT5Service](../MT5Service/2.%20Symbol_Methods.md) / [MT5Account](../MT5Account/2.%20Symbol_information/Symbol_Information.Overview.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/06_sugar_basics.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

## 📋 Methods

| Method | Returns | Value |
|--------|---------|-------|
| **`getSymbolInfo(symbol)`** | `Promise<SymbolParams>` | Full contract spec (~30 fields). |
| **`getAllSymbols()`** | `Promise<string[]>` | Every symbol name the account sees. |
| **`isSymbolAvailable(symbol)`** | `Promise<boolean>` | Does the broker know this symbol? |
| **`getMinStopLevel(symbol)`** | `Promise<number>` | Min SL/TP distance from market, in **points**. |
| **`getSymbolDigits(symbol)`** | `Promise<number>` | Price decimal places. |

> `SymbolParams` (`digits`, `point`, `spread`, `contractSize`, `volumeMin/Max/Step`, `tickValue`, …) is documented in [MT5Service → Symbol Methods](../MT5Service/2.%20Symbol_Methods.md).

## 💡 Usage examples

### 1) Spec at a glance

```ts
const s = await sugar.getSymbolInfo('EURUSD');
console.log(`${s.name}: digits ${s.digits}, point ${s.point}, vol ${s.volumeMin}–${s.volumeMax}/${s.volumeStep}`);
```

### 2) Guard before trading an unknown symbol

```ts
if (!(await sugar.isSymbolAvailable('XAUUSD'))) throw new Error('symbol not available');
```

### 3) Validate stop distance

```ts
const minPts = await sugar.getMinStopLevel('EURUSD');
console.log(`SL/TP must be ≥ ${minPts} points from price`);
```

### 4) Round a price to the symbol's digits

```ts
const digits = await sugar.getSymbolDigits('EURUSD');
const rounded = Number((1.123456).toFixed(digits));
```

### 5) Search the symbol list

```ts
const usd = (await sugar.getAllSymbols()).filter((n) => n.includes('USD'));
console.log(`${usd.length} USD symbols`);
```

---

## 🔧 Notes

- **`getMinStopLevel` is in points**, not pips — compare SL/TP distance against it to avoid retcode `10016`.
- **`getSymbolInfo`** is the efficient "everything about a symbol" call — prefer it over several property reads.
- **`isSymbolAvailable`** checks existence; a symbol can exist but still need selecting into Market Watch before it quotes ([`ensureSymbol`](../MT5Service/2.%20Symbol_Methods.md)).
