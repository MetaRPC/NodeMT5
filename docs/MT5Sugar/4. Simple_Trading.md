# MT5Sugar — Simple Trading (High-Level API)

> Place market and pending orders in one line — returns the ticket, throws on rejection.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [`MT5Service.placeOrder`](../MT5Service/4.%20Trading_Methods.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 🛑 Result model — ticket or throw

Unlike the lower layers (which hand back a result with a `retcode`), the trading sugar **throws `MrpcError` on a broker rejection** (retcode ≠ `10009`) and otherwise **returns the ticket number**. So you wrap calls in `try/catch` instead of checking a code.

```ts
try {
  const ticket = await sugar.buyMarket('EURUSD', 0.1);
  console.log('opened #', ticket);
} catch (e) {
  console.error('rejected:', (e as Error).message); // carries the retcode
}
```

---

## 📋 Methods

| Method | Returns | Order |
|--------|---------|-------|
| **`buyMarket(symbol, volume)`** | `Promise<number>` | Market BUY. |
| **`sellMarket(symbol, volume)`** | `Promise<number>` | Market SELL. |
| **`buyLimit(symbol, volume, price)`** | `Promise<number>` | BUY LIMIT at `price`. |
| **`sellLimit(symbol, volume, price)`** | `Promise<number>` | SELL LIMIT at `price`. |
| **`buyStop(symbol, volume, price)`** | `Promise<number>` | BUY STOP at `price`. |
| **`sellStop(symbol, volume, price)`** | `Promise<number>` | SELL STOP at `price`. |

> Returns the **ticket** (the position ticket for a filled market order). Need SL/TP in the same call? → [Trading with SL/TP](./5.%20Trading_SLTP.md) or [Trading Helpers](./11.%20Trading_Helpers.md).

## 💡 Usage examples

### 1) Market BUY

```ts
const ticket = await sugar.buyMarket('EURUSD', 0.1);
console.log('position #', ticket);
```

### 2) Pending BUY LIMIT below market

```ts
const bid = await sugar.getBid('EURUSD');
const ticket = await sugar.buyLimit('EURUSD', 0.1, bid - 0.0020); // 20 pips below
```

### 3) Breakout SELL STOP

```ts
const bid = await sugar.getBid('EURUSD');
await sugar.sellStop('EURUSD', 0.1, bid - 0.0015);
```

### 4) Guard with canOpenPosition first

```ts
const { ok, reason } = await sugar.canOpenPosition('EURUSD', 0.1);
if (!ok) throw new Error(reason);
const ticket = await sugar.buyMarket('EURUSD', 0.1);
```

### 5) Handle a closed market gracefully

```ts
try {
  await sugar.buyMarket('EURUSD', 0.1);
} catch (e) {
  const msg = (e as Error).message;
  if (msg.includes('10018')) console.log('market closed — try later');
  else throw e;
}
```

---

## 🔧 Notes

- **Throws, doesn't return a code.** A rejection becomes an `MrpcError` whose message/code carries the retcode (e.g. `10018` market closed, `10019` no money, `10016` invalid stops).
- **Market vs pending.** Market orders (`buyMarket`/`sellMarket`) fill at the live quote; `*Limit` / `*Stop` rest at `price` until triggered.
- **Volume rules.** Respect the symbol's min/step — see [`canOpenPosition`](./10.%20Risk_Management.md) / [`getSymbolInfo`](./9.%20Symbol_Information.md).
