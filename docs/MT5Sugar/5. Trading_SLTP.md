# MT5Sugar — Trading with SL/TP (High-Level API)

> Place an order with **absolute** stop-loss and take-profit prices in a single call.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [`MT5Service.placeOrder`](../MT5Service/4.%20Trading_Methods.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/07_sugar_trading.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Order |
|--------|---------|-------|
| **`buyMarketWithSLTP(symbol, volume, sl, tp)`** | `Promise<number>` | Market BUY + SL/TP. |
| **`sellMarketWithSLTP(symbol, volume, sl, tp)`** | `Promise<number>` | Market SELL + SL/TP. |
| **`buyLimitWithSLTP(symbol, volume, price, sl, tp)`** | `Promise<number>` | BUY LIMIT at `price` + SL/TP. |
| **`sellLimitWithSLTP(symbol, volume, price, sl, tp)`** | `Promise<number>` | SELL LIMIT at `price` + SL/TP. |

> `sl` / `tp` are **absolute prices**, not distances. For **pip distances** use [`buyMarketWithPips` / `sellMarketWithPips`](./11.%20Trading_Helpers.md), or compute levels with [`calculateSLTP`](./10.%20Risk_Management.md). Like [Simple Trading](./4.%20Simple_Trading.md), these **return the ticket** and **throw `MrpcError`** on rejection.

---

## 💡 Usage examples

### 1) Market BUY with fixed levels

```ts
const ticket = await sugar.buyMarketWithSLTP('EURUSD', 0.1, 1.0800, 1.0900);
```

### 2) Levels from pip distances via calculateSLTP

```ts
const ask = await sugar.getAsk('EURUSD');
const { sl, tp } = await sugar.calculateSLTP('EURUSD', 'BUY', ask, 20, 40); // 20 pip SL, 40 pip TP
const ticket = await sugar.buyMarketWithSLTP('EURUSD', 0.1, sl, tp);
```

### 3) Pending SELL LIMIT with protection

```ts
const bid = await sugar.getBid('EURUSD');
await sugar.sellLimitWithSLTP('EURUSD', 0.1, bid + 0.0020, bid + 0.0040, bid - 0.0020);
```

### 4) Risk-sized entry with SL/TP

```ts
const lots = await sugar.calculatePositionSize('EURUSD', 1, 20); // risk 1% over a 20-pip stop
const ask = await sugar.getAsk('EURUSD');
const { sl, tp } = await sugar.calculateSLTP('EURUSD', 'BUY', ask, 20, 40);
await sugar.buyMarketWithSLTP('EURUSD', lots, sl, tp);
```

### 5) Validate stops distance first

```ts
const minPts = await sugar.getMinStopLevel('EURUSD'); // minimum SL/TP distance, points
// ensure your sl/tp are at least minPts away from price, else expect retcode 10016
```

---

## 🔧 Notes

- **Absolute prices.** `sl`/`tp` are levels, not offsets — mind the symbol's digits.
- **Stops level.** SL/TP closer than [`getMinStopLevel`](./9.%20Symbol_Information.md) → rejection (`10016`).
- **BUY vs SELL geometry.** For a BUY, `sl < price < tp`; for a SELL, `tp < price < sl`.

## 🎯 Summary

Four one-liners place market or limit orders with absolute SL/TP and return the ticket. Feed them levels from `calculateSLTP`, or use the pip-distance helpers when you think in pips rather than prices.
