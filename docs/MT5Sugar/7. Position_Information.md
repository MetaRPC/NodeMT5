# MT5Sugar — Position Information (High-Level API)

> Read open positions — all, by ticket, by symbol, counts and floating profit.

**🧩 API Layer:** **HIGH-LEVEL** — one-liners over [`MT5Service.getPositions`](../MT5Service/3.%20Position_Orders_Methods.md).

**Implementation:** `src/MT5Sugar.ts`. **Demos:** `examples/demos/sugar/08_sugar_positions.js`.

[← MT5Sugar API Overview](./MT5Sugar.API_Overview.md)

---

## 📋 Methods

| Method | Returns | Value |
|--------|---------|-------|
| **`getOpenPositions()`** | `Promise<Position[]>` | All open positions. |
| **`getPositionByTicket(ticket)`** | `Promise<Position \| undefined>` | One position, or `undefined`. |
| **`getPositionsBySymbol(symbol)`** | `Promise<Position[]>` | Positions on one symbol. |
| **`hasOpenPosition(symbol)`** | `Promise<boolean>` | Any position on a symbol? |
| **`countOpenPositions()`** | `Promise<number>` | Number of open positions. |
| **`getTotalProfit()`** | `Promise<number>` | Summed floating profit, all positions. |
| **`getProfitBySymbol(symbol)`** | `Promise<number>` | Summed floating profit on one symbol. |

> The `Position` object (`ticket`, `symbol`, `type` 0=BUY/1=SELL, `volume`, `priceOpen`, `priceCurrent`, `profit`, `magic`, …) is documented in [MT5Service → Positions & Orders](../MT5Service/3.%20Position_Orders_Methods.md).

## 💡 Usage examples

### 1) List open positions

```ts
for (const p of await sugar.getOpenPositions()) {
  console.log(`#${p.ticket} ${p.symbol} ${p.type === 0 ? 'BUY' : 'SELL'} ${p.volume} → ${p.profit.toFixed(2)}`);
}
```

### 2) One position by ticket

```ts
const p = await sugar.getPositionByTicket(123456);
if (!p) console.log('not open');
```

### 3) Avoid stacking on a symbol

```ts
if (!(await sugar.hasOpenPosition('EURUSD'))) {
  await sugar.buyMarket('EURUSD', 0.1);
}
```

### 4) Floating P&L, total and per symbol

```ts
console.log('total floating:', (await sugar.getTotalProfit()).toFixed(2));
console.log('EURUSD floating:', (await sugar.getProfitBySymbol('EURUSD')).toFixed(2));
```

### 5) Exposure by symbol

```ts
const eur = await sugar.getPositionsBySymbol('EURUSD');
const net = eur.reduce((s, p) => s + (p.type === 0 ? p.volume : -p.volume), 0);
console.log('EURUSD net lots:', net);
```

### 6) Position cap

```ts
if (await sugar.countOpenPositions() >= 5) console.log('max concurrent positions reached');
```

---

## 🔧 Notes

- **Open positions only.** For closed trades use [History & Statistics](./8.%20History_Statistics.md).
- **`profit` is floating.** It's the live unrealized P&L of each open position.
- **`type`:** `0` = BUY, `1` = SELL.

## 🎯 Summary

Seven reads over the open-positions list: the full array, lookup by ticket or symbol, existence/count, and summed floating profit (total or per symbol). All derive from one `getPositions()` call under the hood.
