# MT5Service — Symbol Methods (Mid-Level API)

> Quotes, symbol discovery, contract specs, sessions and price history — as plain typed objects, no protobuf.

**🧩 API Layer:** **MID-LEVEL** — a friendly facade over the low-level [Symbol Information](../MT5Account/2.%20Symbol_information/Symbol_Information.Overview.md) and [Additional Methods](../MT5Account/6.%20Additional_Methods/Additional_Methods.Overview.md) groups.

**Implementation:** `src/MT5Service.ts`. **Demos:** `examples/demos/service/04_service_demo.js`.

[← MT5Service Overview](./MT5Service.Overview.md) · [low-level group ↓](../MT5Account/2.%20Symbol_information/Symbol_Information.Overview.md)

---

## 🎯 Why these methods exist

On `MT5Account`, each symbol read means building a `*Request`, setting `symbol` + a property enum, and unwrapping `*Data`:

```ts
// Low-level
import { MarketInfoPb } from '@metarpc/nodemt5';
const req = new MarketInfoPb.SymbolInfoDoubleRequest();
req.setSymbol('EURUSD');
req.setType(MarketInfoPb.SymbolInfoDoubleProperty.SYMBOL_BID);
const bid = (await account.symbolInfoDouble(req)).getValue();
```

`MT5Service` collapses the common reads into one call that returns a plain value or a typed object:

```ts
// Mid-level
const tick = await service.getSymbolTick('EURUSD');   // → Quote { bid, ask, last, … }
const spec = await service.getSymbolParams('EURUSD'); // → SymbolParams (~30 fields)
```

## 📋 All methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`getSymbolsTotal(selectedOnly?)`** | `Promise<number>` | Count of symbols (all, or Market-Watch only). |
| **`symbolExist(symbol)`** | `Promise<{ exists, isCustom }>` | Does a symbol exist (and is it custom)? |
| **`getSymbolName(index, selectedOnly?)`** | `Promise<string>` | Symbol name by index. |
| **`symbolSelect(symbol, select?)`** | `Promise<boolean>` | Add / remove from Market Watch. |
| **`isSymbolSynchronized(symbol)`** | `Promise<boolean>` | Are the symbol's rates synced? |
| **`ensureSymbol(symbol, waitMs?)`** | `Promise<Quote>` | Select + wait for a two-sided quote. |
| **`getSymbolTick(symbol)`** | `Promise<Quote>` | Latest tick (the reliable price). |
| **`getSymbolDouble(symbol, property)`** | `Promise<number>` | One `SYMBOL_*` double. |
| **`getSymbolInteger(symbol, property)`** | `Promise<number>` | One `SYMBOL_*` integer. |
| **`getSymbolString(symbol, property)`** | `Promise<string>` | One `SYMBOL_*` string. |
| **`getSymbolParams(symbol)`** | `Promise<SymbolParams>` | Full contract spec for one symbol. |
| **`getSymbolParamsMany()`** | `Promise<SymbolParams[]>` | Full spec for all symbols in one call. |
| **`getSymbolMarginRate(symbol, orderType)`** | `Promise<SymbolMarginRate>` | Initial / maintenance margin rate. |
| **`getSymbolSessionQuote(symbol, dayOfWeek, sessionIndex?)`** | `Promise<SessionTime>` | Quote-session window for a weekday. |
| **`getSymbolSessionTrade(symbol, dayOfWeek, sessionIndex?)`** | `Promise<SessionTime>` | Trade-session window for a weekday. |
| **`priceHistory(symbol, timeframe, opts?)`** | `Promise<Bar[]>` | OHLC bars in a range. |

## 📦 DTOs

### `Quote` — from `getSymbolTick` / the tick stream

| Field | Type | Description |
| ----- | ---- | ----------- |
| `symbol` | `string` | Instrument. |
| `bid` / `ask` / `last` | `number` | Best prices. |
| `volume` | `number` | Tick volume. |
| `time` | `number` | Tick time — **milliseconds** since epoch. |
| `flags` | `number` | Tick flags bitmask. |

### `SymbolParams` — from `getSymbolParams` / `getSymbolParamsMany`

`name` · `digits` · `point` · `bid` · `ask` · `spread` · `contractSize` · `tickSize` · `tickValue` · `volumeMin` · `volumeMax` · `volumeStep` · `volumeLimit` · `swapLong` · `swapShort` · `stopsLevel` · `freezeLevel` · `tradeMode` · `tradeCalcMode` · `tradeExeMode` · `fillingModes: number[]` · `currencyBase` · `currencyProfit` · `currencyMargin` · `description` · `path` · `visible` · `selected` · `exists`.

### `Bar` — from `priceHistory`

`time` (seconds, server tz) · `open` · `high` · `low` · `close` · `tickVolume` · `spread` · `realVolume`.

### `SymbolMarginRate` — `initialMarginRate`, `maintenanceMarginRate`. `SessionTime` — `from`, `to` (seconds since epoch).

## 📖 Method details

### Inventory & Market Watch

```ts
const total   = await service.getSymbolsTotal();          // all symbols
const inWatch = await service.getSymbolsTotal(true);      // Market Watch only
const first   = await service.getSymbolName(0);           // name by index
const { exists, isCustom } = await service.symbolExist('EURUSD');
const ok      = await service.symbolSelect('GBPUSD', true); // add to Market Watch
const synced  = await service.isSymbolSynchronized('EURUSD');
```

**`ensureSymbol(symbol, waitMs = 10000)`** — selects the symbol and polls until it has a two-sided quote (a freshly added symbol reports `bid/ask = 0` until synchronized). Returns the first usable `Quote`. Use it before trading a symbol you just added.

### Prices

```ts
const tick = await service.getSymbolTick('EURUSD');
console.log(`Bid ${tick.bid}, Ask ${tick.ask}, Spread ${(tick.ask - tick.bid).toFixed(5)}`);
```

**`priceHistory(symbol, timeframe, opts?)`** — `timeframe` is a string key (`'M1'`, `'M5'`, `'M15'`, `'M30'`, `'H1'`, `'H4'`, `'D1'`, `'W1'`, `'MN1'`, …) or the raw numeric code; `opts = { from?, to?, maxBars? }`:

```ts
const bars = await service.priceHistory('EURUSD', 'H1', { from: new Date(Date.now() - 24 * 3600e3), maxBars: 24 });
console.log(`${bars.length} bars, last close ${bars.at(-1)?.close}`);
```

### Single properties

```ts
import { MarketInfoPb } from '@metarpc/nodemt5';
const point  = await service.getSymbolDouble('EURUSD', MarketInfoPb.SymbolInfoDoubleProperty.SYMBOL_POINT);
const digits = await service.getSymbolInteger('EURUSD', MarketInfoPb.SymbolInfoIntegerProperty.SYMBOL_DIGITS);
const desc   = await service.getSymbolString('EURUSD', MarketInfoPb.SymbolInfoStringProperty.SYMBOL_DESCRIPTION);
```

### Full contract spec

```ts
const s = await service.getSymbolParams('EURUSD');
console.log(`${s.name}: ${s.volumeMin}–${s.volumeMax} (step ${s.volumeStep}), contract ${s.contractSize}, digits ${s.digits}`);

const all = await service.getSymbolParamsMany(); // every symbol in one call
```

### Margin rate & sessions

```ts
const rate = await service.getSymbolMarginRate('EURUSD', 'BUY'); // OrderAction string
console.log(rate.initialMarginRate, rate.maintenanceMarginRate);

const sess = await service.getSymbolSessionTrade('EURUSD', 1);   // 1 = Monday, sessionIndex defaults to 0
console.log(`Mon trade session ${(sess.from / 3600).toFixed(2)}h → ${(sess.to / 3600).toFixed(2)}h`);
```

> `dayOfWeek`: `0` = Sunday … `6` = Saturday. Session `from`/`to` are seconds since midnight (server time) — divide by 3600 for the hour.

## 💡 Usage examples

### 1) Spread right now

```ts
const t = await service.getSymbolTick('EURUSD');
console.log(`Spread: ${((t.ask - t.bid) / (await service.getSymbolParams('EURUSD')).point).toFixed(0)} points`);
```

### 2) List the Market-Watch symbols

```ts
const n = await service.getSymbolsTotal(true);
for (let i = 0; i < n; i++) console.log(await service.getSymbolName(i, true));
```

### 3) Make a symbol tradable before use

```ts
const quote = await service.ensureSymbol('XAUUSD'); // selects + waits for a real quote
console.log('ready:', quote.bid, quote.ask);
```

### 4) Pre-trade sizing inputs

```ts
const s = await service.getSymbolParams('EURUSD');
const lots = Math.max(s.volumeMin, Math.round(0.37 / s.volumeStep) * s.volumeStep);
console.log(`Rounded lots: ${lots} (min ${s.volumeMin}, step ${s.volumeStep})`);
```

### 5) Daily range from bars

```ts
const bars = await service.priceHistory('EURUSD', 'D1', { maxBars: 1 });
const d = bars.at(-1);
if (d) console.log(`Today range: ${(d.high - d.low).toFixed(5)} (O ${d.open} C ${d.close})`);
```

### 6) Scan majors' spreads in one call

```ts
const majors = new Set(['EURUSD', 'GBPUSD', 'USDJPY', 'AUDUSD', 'USDCAD']);
for (const s of await service.getSymbolParamsMany()) {
  if (majors.has(s.name)) console.log(`${s.name.padEnd(8)} spread ${s.spread}`);
}
```

## 🔧 When to use which

- **Current price** → `getSymbolTick` (or `streamTicks` for a live feed).
- **All of a symbol's spec** → `getSymbolParams` (one symbol) / `getSymbolParamsMany` (all) — cheaper than many single-property reads.
- **Just one property** → `getSymbolDouble / Integer / String`.
- **About to trade a new symbol** → `ensureSymbol` first.
- **Charts / indicators** → `priceHistory`.

## 🎯 Summary

Symbol methods turn protobuf symbol reads into plain values and typed objects: `getSymbolTick` → `Quote`, `getSymbolParams` → a ~30-field `SymbolParams`, `priceHistory` → `Bar[]`. Discovery (`getSymbolsTotal` / `getSymbolName` / `symbolExist`), Market-Watch (`symbolSelect` / `ensureSymbol`), margin rates and sessions round out the group.
