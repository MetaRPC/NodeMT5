# MT5Service — Positions & Orders Methods (Mid-Level API)

> The order book and the history as plain typed arrays — open positions, pending orders, closed deals and positions.

**🧩 API Layer:** **MID-LEVEL** — a facade over the low-level [Positions & Orders](../MT5Account/3.%20Position_Orders_Information/Position_Orders_Information.Overview.md) group.

**Implementation:** `src/MT5Service.ts`. **Demos:** `examples/demos/service/04_service_demo.js`.

[← MT5Service Overview](./MT5Service.Overview.md) · [low-level group ↓](../MT5Account/3.%20Position_Orders_Information/Position_Orders_Information.Overview.md)

---

## 🎯 Why these methods exist

On `MT5Account`, reading the blotter means unwrapping repeated protobuf lists and calling a getter per field:

```ts
// Low-level
const d = await account.openedOrders();
for (const p of d.getPositionInfosList()) {
  console.log(p.getTicket(), p.getSymbol(), p.getVolume(), p.getProfit());
}
```

`MT5Service` maps each row to a plain object with named fields:

```ts
// Mid-level
const { positions } = await service.getOpenedOrders();
for (const p of positions) console.log(p.ticket, p.symbol, p.volume, p.profit);
```

---

## 📋 All methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`getPositionsTotal()`** | `Promise<number>` | Count of open positions. |
| **`getOpenedOrders()`** | `Promise<{ positions: Position[]; orders: PendingOrder[] }>` | Open positions **and** pending orders. |
| **`getOpenedTickets()`** | `Promise<{ positionTickets: number[]; orderTickets: number[] }>` | Just the ticket numbers (lightweight). |
| **`getPositions(magic?)`** | `Promise<Position[]>` | Open positions, optionally filtered by magic. |
| **`getOrderHistory(from, to, opts?)`** | `Promise<{ orders: HistoryOrder[]; deals: HistoryDeal[] }>` | Closed orders + deals in a window. |
| **`getPositionsHistory(from, to, opts?)`** | `Promise<HistoryPosition[]>` | Closed positions with P&L. |

`from` / `to` accept a `Date` or unix-ms `number`; the SDK converts to the broker-server-time bounds. `opts` carries `{ sort?, page?, perPage? }`.

## 📦 DTOs

### `Position` — open position

`ticket` · `symbol` · `type` (0 = BUY, 1 = SELL) · `volume` · `priceOpen` · `priceCurrent` · `stopLoss` · `takeProfit` · `swap` · `profit` · `commission` · `magic` · `comment` · `openTime` (s) · `identifier`.

### `PendingOrder` — working order

`ticket` · `symbol` · `type` · `state` · `volumeInitial` · `volumeCurrent` · `priceOpen` · `priceCurrent` · `stopLoss` · `takeProfit` · `stopLimit` · `magic` · `comment` · `timeSetup` · `timeExpiration` · `positionId`.

### `HistoryOrder` / `HistoryDeal` — from `getOrderHistory`

- **`HistoryOrder`**: `ticket` · `symbol` · `type` · `state` · `volumeInitial` · `volumeCurrent` · `priceOpen` · `stopLoss` · `takeProfit` · `magic` · `positionId` · `comment` · `timeSetup` · `timeDone`.
- **`HistoryDeal`**: `ticket` · `symbol` · `type` (0 = BUY, 1 = SELL, 2 = BALANCE…) · `entry` (0 = IN, 1 = OUT, 2 = INOUT, 3 = OUT_BY) · `volume` · `price` · `profit` · `commission` · `swap` · `fee` · `positionId` · `comment` · `time` (s).

### `HistoryPosition` — from `getPositionsHistory`

`ticket` · `symbol` · `type` · `volume` · `openTime` · `closeTime` · `openPrice` · `closePrice` · `stopLoss` · `takeProfit` · `profit` · `commission` · `swap` · `fee` · `magic` · `comment`.

> **MT5 model:** a **position** is net exposure; a **pending order** rests until triggered; a **deal** is an executed transaction. Realized P&L lives on deals / closed positions, not on open positions.

## 📖 Method details

```ts
// Count
const n = await service.getPositionsTotal();

// Full blotter
const { positions, orders } = await service.getOpenedOrders();

// Tickets only (cheap poll)
const { positionTickets, orderTickets } = await service.getOpenedTickets();

// Positions of one strategy (by magic)
const mine = await service.getPositions(123456);
```

```ts
// History — last 7 days
const now = new Date();
const weekAgo = new Date(now.getTime() - 7 * 24 * 3600e3);

const { orders, deals } = await service.getOrderHistory(weekAgo, now, { page: 1, perPage: 100 });
const closed = await service.getPositionsHistory(weekAgo, now);
```

## 💡 Usage examples

### 1) Total floating P&L

```ts
const { positions } = await service.getOpenedOrders();
const floating = positions.reduce((s, p) => s + p.profit + p.swap, 0);
console.log(`Floating P&L: ${floating.toFixed(2)}`);
```

### 2) Biggest loser right now

```ts
const { positions } = await service.getOpenedOrders();
const worst = positions.reduce((a, b) => (b.profit < a.profit ? b : a), positions[0]);
if (worst) console.log(`Worst: #${worst.ticket} ${worst.symbol} ${worst.profit.toFixed(2)}`);
```

### 3) Lightweight "anything open?" poll

```ts
const { positionTickets, orderTickets } = await service.getOpenedTickets();
console.log(positionTickets.length === 0 && orderTickets.length === 0 ? 'flat' : 'in the market');
```

### 4) Per-strategy exposure by magic

```ts
const mine = await service.getPositions(777);
const net = mine.reduce((s, p) => s + (p.type === 0 ? p.volume : -p.volume), 0);
console.log(`Strategy 777 net volume: ${net}`);
```

### 5) Realized P&L today

```ts
const now = new Date();
const start = new Date(now.getFullYear(), now.getMonth(), now.getDate());
const closed = await service.getPositionsHistory(start, now);
console.log(`Realized today: ${closed.reduce((s, p) => s + p.profit, 0).toFixed(2)} over ${closed.length} positions`);
```

### 6) Deals of a single position

```ts
const { deals } = await service.getOrderHistory(new Date(Date.now() - 30 * 24 * 3600e3), new Date());
const posId = 123456;
for (const d of deals.filter((x) => x.positionId === posId)) {
  console.log(`${d.entry === 0 ? 'IN ' : 'OUT'} ${d.volume} @ ${d.price} → ${d.profit}`);
}
```

## 🔧 When to use which

- **Just a count** → `getPositionsTotal`.
- **Full detail of what's open** → `getOpenedOrders` (positions + pending) or `getPositions` (positions, magic-filtered).
- **Cheap change-detection loop** → `getOpenedTickets`.
- **What closed and for how much** → `getPositionsHistory` (per closed position) or `getOrderHistory` (raw orders + deals).

## 🎯 Summary

Positions & Orders methods return plain typed arrays instead of repeated protobuf lists: `Position[]`, `PendingOrder[]`, `HistoryOrder[]` / `HistoryDeal[]`, `HistoryPosition[]`. `Date` goes in, named fields come out, and `magic` / paging keep large result sets manageable.
