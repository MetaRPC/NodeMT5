# MT5Service — Market Depth Methods (Mid-Level API)

> Level-II order book as a plain `BookInfo[]` — subscribe, read, unsubscribe.

**🧩 API Layer:** **MID-LEVEL** — a facade over the low-level [Market Depth (DOM)](../MT5Account/5.%20Market_Depth(DOM)/Market_Depth.Overview.md) group.

**Implementation:** `src/MT5Service.ts`. **Demos:** `examples/demos/service/04_service_demo.js`.

[← MT5Service Overview](./MT5Service.Overview.md) · [low-level group ↓](../MT5Account/5.%20Market_Depth(DOM)/Market_Depth.Overview.md)

---

## 🎯 Why these methods exist

On `MT5Account`, reading the book means a `MarketBookGetRequest` and unwrapping a repeated protobuf list. `MT5Service` returns a mapped array of plain objects and simplifies subscribe/release to a boolean:

```ts
// Mid-level
const ok   = await service.subscribeMarketDepth('EURUSD');
const book = await service.getMarketDepth('EURUSD'); // → BookInfo[]
await service.unsubscribeMarketDepth('EURUSD');
```

---

## 📋 All methods

| Method | Returns | Purpose |
|--------|---------|---------|
| **`subscribeMarketDepth(symbol)`** | `Promise<boolean>` | Open the book on the gateway. |
| **`getMarketDepth(symbol)`** | `Promise<BookInfo[]>` | Current book snapshot (rows). |
| **`unsubscribeMarketDepth(symbol)`** | `Promise<boolean>` | Close the subscription. |

Call **subscribe → get (repeatedly) → unsubscribe**.

---

## 📦 `BookInfo` (DTO)

| Field | Type | Description |
| ----- | ---- | ----------- |
| `type` | `number` | MQL5 `ENUM_BOOK_TYPE` — `1` = sell, `2` = buy, `3`/`4` = sell/buy market. |
| `price` | `number` | Level price. |
| `volume` | `number` | Volume (integer units). |
| `volumeReal` | `number` | Volume (real/lots). |

> **⚠️ DOM availability.** Depth of Market is usually **not** available for forex on demo accounts — `subscribeMarketDepth` may resolve `false`. It's meaningful for exchange-traded instruments.

## 💡 Usage examples

### 1) Subscribe and read once

```ts
if (await service.subscribeMarketDepth('EURUSD')) {
  const book = await service.getMarketDepth('EURUSD');
  console.log(`${book.length} levels`);
  await service.unsubscribeMarketDepth('EURUSD');
} else {
  console.log('DOM not available for this symbol/account');
}
```

### 2) Split by side

```ts
const book = await service.getMarketDepth('EURUSD');
const buys  = book.filter((r) => r.type === 2);
const sells = book.filter((r) => r.type === 1);
console.log('best bid', Math.max(...buys.map((r) => r.price)), 'best ask', Math.min(...sells.map((r) => r.price)));
```

### 3) Order-book imbalance

```ts
const book = await service.getMarketDepth('EURUSD');
let buyVol = 0, sellVol = 0;
for (const r of book) (r.type === 2 ? (buyVol += r.volumeReal) : (sellVol += r.volumeReal));
console.log(buyVol > sellVol ? '📈 bullish pressure' : '📉 bearish pressure');
```

### 4) Poll with cleanup

```ts
await service.subscribeMarketDepth('EURUSD');
const timer = setInterval(async () => {
  const book = await service.getMarketDepth('EURUSD');
  console.log(`${new Date().toLocaleTimeString()} — ${book.length} levels`);
}, 1000);

// later:
clearInterval(timer);
await service.unsubscribeMarketDepth('EURUSD');
```

---

## 🔧 Notes & gotchas

- **Subscribe first.** `getMarketDepth` returns rows only after a successful `subscribeMarketDepth`.
- **Add to Market Watch.** Use [`symbolSelect`](./2.%20Symbol_Methods.md) if the symbol isn't selected.
- **Always unsubscribe.** Release the book when done to free the subscription.

## 🎯 Summary

Market Depth methods wrap the DOM subscription into three calls that return booleans and a mapped `BookInfo[]`, so you work with plain `{ type, price, volume, volumeReal }` rows instead of protobuf lists.
