    MT5Service — Streaming Methods (Mid-Level API)¶

    Real-time subscriptions with a simple callback model — ticks as typed Quotes, plus trade, P&L, ticket and transaction streams.

    🧩 API Layer: MID-LEVEL — a facade over the low-level Streaming Methods group.

    Implementation: src/MT5Service.ts. Demos: examples/demos/service/05_service_streaming.js.

    ← MT5Service Overview · low-level group ↓

    🎯 The subscription model¶

    Every streaming method returns a Subscription — { unsubscribe(): void } — and calls your callback per payload. Errors go to the optional onError. The SDK attaches the session guid + api key automatically — just connect() first.

    const sub = service.streamTicks(['EURUSD'], (quote) => { /* … */ });
// later:
sub.unsubscribe();

    Always keep the Subscription and unsubscribe() when done — an un-cancelled stream keeps the gRPC call (and terminal) alive.

    📋 All methods¶

    Method Callback payload Notes
    streamTicks(symbols, cb, onError?) Quote (mapped) Live Bid/Ask for one or more symbols.
    streamTradeUpdates(cb, onError?) raw OnTradeData "Something changed" — orders/positions/deals.
    streamPositionProfits(cb, onError?) raw OnPositionProfitData Periodic open-position P&L.
    streamOpenedTickets(cb, onError?) raw OnPositionsAndPendingOrdersTicketsData Periodic ticket snapshots.
    streamTransactions(cb, onError?) raw OnTradeTransactionData Raw trade-transaction detail.

    Mapped vs raw. streamTicks delivers a typed Quote ({ symbol, bid, ask, last, volume, time, flags }). The other four pass the raw low-level *Data message — read it with the same getXxx() accessors documented on the low-level streaming pages. This keeps every field reachable without a lossy mapping.

    📖 Method details¶

    // Ticks → typed Quote
const t = service.streamTicks(['EURUSD', 'GBPUSD'], (q) => {
  console.log(`${q.symbol}: ${q.bid}/${q.ask}`);
}, (e) => console.error(e.message));

// Trade events (raw payload)
const u = service.streamTradeUpdates((data) => console.log('event type', data.getType()));

// Periodic P&L (raw payload)
const p = service.streamPositionProfits((data) => {
  for (const pos of data.getUpdatedPositionsList()) {
    console.log(`#${pos.getTicket()} ${pos.getPositionSymbol()} ${pos.getProfit().toFixed(2)}`);
  }
});

// Ticket snapshots (raw payload)
const k = service.streamOpenedTickets((data) => {
  console.log('positions:', data.getPositionTicketsList());
});

// Transactions (raw payload)
const x = service.streamTransactions((data) => {
  const tx = data.getTradeTransaction();
  console.log('deal#', tx.getDealTicket(), 'order#', tx.getOrderTicket());
});

    💡 Usage examples¶

    1) Live price print¶

    const sub = service.streamTicks(['EURUSD'], (q) => console.log(q.symbol, q.bid, q.ask));

    2) Spread alert¶

    const sub = service.streamTicks(['EURUSD'], (q) => {
  const spread = q.ask - q.bid;
  if (spread > 0.0003) console.warn(`wide spread: ${(spread * 1e5).toFixed(0)} pts`);
});

    3) Re-pull the blotter on any trade event¶

    const sub = service.streamTradeUpdates(async () => {
  const { positions } = await service.getOpenedOrders();
  console.log('positions now:', positions.length);
});

    4) Floating-P&L ticker¶

    const sub = service.streamPositionProfits((data) => {
  const total = data.getUpdatedPositionsList().reduce((s: number, p: any) => s + p.getProfit(), 0);
  console.log('floating:', total.toFixed(2));
});

    5) Stop when flat¶

    const sub = service.streamOpenedTickets((data) => {
  if (data.getPositionTicketsList().length === 0) { console.log('all closed'); sub.unsubscribe(); }
});

    6) Several streams, one cleanup¶

    const subs = [
  service.streamTicks(['EURUSD'], (q) => console.log('[TICK]', q.bid)),
  service.streamTradeUpdates((d) => console.log('[TRADE]', d.getType())),
];
// later:
for (const s of subs) s.unsubscribe();

    🔧 Notes & gotchas¶

    • Callbacks, not channels — no manual loop; the SDK reads the stream for you.
    • streamTicks is high-frequency — keep the callback cheap.
    • P&L has no symbol filter — streamPositionProfits streams all positions; filter by getPositionSymbol() in the callback.
    • Always unsubscribe() — streams don't stop on their own.
    • Need typed objects for every stream? Drop to the low-level pages, or use MT5Sugar.onTick / onTrade.

    🎯 Summary¶

    Streaming methods expose a uniform Subscription callback model. streamTicks gives you typed Quotes; the trade/P&L/ticket/transaction streams pass the raw low-level payload so no field is lost. Keep the handle, unsubscribe() when done.
